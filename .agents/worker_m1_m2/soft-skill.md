# Soft Skill: High-End Visual Design

Key Principles:
- Editorial Luxury / Ethereal Glass
- Double-bezel card architecture (outer shell + inner core)
- Button-in-button trailing icon islands
- Custom cubic-bezier spring motion: cubic-bezier(0.16, 1, 0.3, 1) and cubic-bezier(0.32, 0.72, 0, 1)
- 360px+ mobile resilience (min-h-[100dvh], floating nav, sticky bottom action bar)
- Zero banned fonts (using Playfair Display / Cormorant Garamond for display serif, Plus Jakarta Sans / Geist for UI sans)
- Zero harsh borders or heavy generic shadows.
